# Project Philosophy

## What This Project Is

**Ukiyo Kanban** is a personal productivity tool with a Japanese woodblock-print (ukiyo-e) aesthetic. It is a modern, offline-first kanban board designed for individual task management.

- A beautiful, minimal kanban board for personal use
- Offline-first by design — the app works without a network connection
- Mobile-friendly — touch interactions, responsive layout
- A demonstration of modern SvelteKit + Svelte 5 runes
- An open-source reference for Svelte best practices

## What This Project Is NOT

- Jira, Trello Enterprise, Asana, or any team collaboration tool
- A SaaS product with user quotas, billing, or multi-tenancy
- An enterprise project management suite
- A generic todo app clone

## Vision

Personal productivity, beautifully rendered. Every feature must serve the individual user, not teams. The goal is to build the kanban board we want to use ourselves — fast, offline, beautiful, and simple.

## Long-Term Goals

- **Offline-first**: The app should function fully without a network connection. Sync when connected. Work when disconnected.
- **Mobile-first**: Design for small screens first. Enhance for larger screens.
- **Beautiful and minimal**: The ukiyo-e aesthetic is not cosmetic — it's a core product differentiator. Every visual detail matters.
- **Personal productivity**: Features are chosen for individual users. No team features. No workspace management. No enterprise bloat.

## Boundaries

| In Scope | Out of Scope |
|----------|-------------|
| Personal task management | Team collaboration |
| Offline capability | Real-time multi-user sync |
| Beautiful design | Enterprise feature requests |
| SvelteKit + Turso | Other backends or databases |
| Individual productivity | Workspace / organization management |
