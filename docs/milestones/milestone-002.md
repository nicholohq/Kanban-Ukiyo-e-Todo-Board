# Milestone 002: PWA Foundation

## Objective

Make Ukiyo Kanban installable as a Progressive Web App with a functional offline shell and pass Lighthouse PWA audit.

## Deliverables

- [✓] Web App Manifest (generated by @vite-pwa/sveltekit)
- [✓] App Icons (192x192, 512x512, maskable, apple-touch-icon)
- [✓] Service Worker (injectManifest via @vite-pwa/sveltekit)
- [✓] Runtime caching (fonts, API responses)
- [✓] Install Prompt UI component
- [✓] Update Toast with idle-aware activation
- [✓] Offline app shell (precached)
- [✓] PWA Store for app state
- [✓] Documentation (ADR-002, feature spec, session log)
- [✓] Cache versioning with schema-based naming

## Acceptance Criteria

- [✓] Application is installable on Chrome desktop
- [✓] Application is installable on Android Chrome
- [✓] App shell loads without network access
- [✓] Existing offline task workflow continues to function
- [✓] Update notifications are non-disruptive (idle-aware)
- [✓] No regressions to authentication or task CRUD
- [✓] Lighthouse PWA audit pass ≥ 90 (verified in build output)
- [✓] Documentation updated

## Architecture Decisions

| Decision | Choice | ADR |
|----------|--------|-----|
| PWA Plugin | @vite-pwa/sveltekit | ADR-002 |
| SW Strategy | injectManifest (Day 1) | ADR-002 |
| Cache Versioning | Schema-based (ukiyo-{purpose}-v{version}) | ADR-002 |
| Update Strategy | Idle-aware activation | ADR-002 |
| Storage | localStorage (unchanged) | ADR-002 |
